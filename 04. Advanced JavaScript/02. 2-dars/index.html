04. Advanced JavaScript (10X Versiya)

DOM Elementlarini Yaratish va O'chirish: createElement, appendChild, remove

Dinamik elementlar yasash, ularga stil va matn berish, sahifaning turli nuqtalariga joylashtirish va o'chirish.

🏗️ 1. Dinamik Element Yaratish Qadamlari

JavaScript orqali yangi HTML elementi 3 qadamda sahifaga qo'shiladi:

  1. Yaratish: const div = document.createElement('div');
  2. Tarkib va stillar berish: div.textContent = "Salom!"; div.classList.add('card');
  3. Sahifaga ulash: otaElement.appendChild(div); yoki otaElement.prepend(div);

🗑️ 2. Elementni O'chirish

Zamonaviy JavaScriptda elementni o'chirish juda oson: element.remove();

Senior Dasturchi Maslahati (Clean Code)

DOM bilan ishlashda har doim Event Delegation (bitta umumiy ota elementga event qo'yish) orqali xotira sarfini tejang.

Xotirada Nima Bo'ladi? (Under The Hood)

DOM elementlari brauzer xotirasida (C++ Render Tree) saqlanadi. Har safar DOM o'zgarganda layout qayta hisoblanishi mumkin.
