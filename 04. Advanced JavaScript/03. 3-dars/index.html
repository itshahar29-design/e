04. Advanced JavaScript (10X Versiya)

Modal Oyna Loyihasi: HTML, CSS, JS va Overlay Arxitekturasi

Pop-up oyna yasash, qorong'i fon (overlay), oyna ochish-yopish, klaviatura (Escape) orqali yopish.

💗 1. Modal Oyna Arxitekturasi

Modal oyna (Popup) zamonaviy veb-saytlarning ajralmas qismidir. U 3 asosiy qismdan iborat:

  • Trigger Button: Modalni ochuvchi tugma.
  • Overlay: Butun ekranni qoplab turuvchi qorong'i shaffof fon.
  • Modal Box: Markazda joylashgan dialog oynasi va uni yopish ("X") tugmasi.

⌨️ 2. Escape Tugmasi Bilan Yopish

Professional dasturchilar modal oynani nafaqat tugma yoki fonga bosganda, balki foydalanuvchi klaviaturadagi Escape tugmasini bosganda ham yopiladigan qiladi.

Senior Dasturchi Maslahati (Clean Code)

DOM bilan ishlashda har doim Event Delegation (bitta umumiy ota elementga event qo'yish) orqali xotira sarfini tejang.

Xotirada Nima Bo'ladi? (Under The Hood)

DOM elementlari brauzer xotirasida (C++ Render Tree) saqlanadi. Har safar DOM o'zgarganda layout qayta hisoblanishi mumkin.
