04. Advanced JavaScript (10X Versiya)

Array Metodlari: Map va Filter Chuqur Tahlili

Funksional dasturlash asoslari: map bilan massivni o'zgartirish, filter bilan saralash va ularni zanjir qilish.

🗺️ 1. Array.prototype.map()

map() massivning har bir elementini qabul qilib, uni o'zgartirib, bir xil uzunlikdagi yangi massiv hosil qiladi:

const sonlar = [1, 2, 3, 4];
const kvadratlar = sonlar.map(x => x * x); // [1, 4, 9, 16]

🔍 2. Array.prototype.filter()

filter() shartga mos keladigan (true qaytargan) elementlarni ajratib olib yangi qisqartirilgan massiv qaytaradi:

const juftlar = sonlar.filter(x => x % 2 === 0); // [2, 4]
