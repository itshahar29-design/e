04. Advanced JavaScript (10X Versiya)

KeyboardEvents: Klaviatura Hodisalari (keydown, keyup, e.key)

Klaviaturadan bosilgan tugmalarni tutib olish, e.key, e.code, e.keyCode va o'yinlar hamda qisqa yo'llar (shortcuts) yasash.

⌨️ 1. Klaviatura Hodisalari

  • keydown — Tugma bosilgan paytda ishga tushadi.
  • keyup — Tugma qo'yib yuborilgan paytda ishga tushadi.
window.addEventListener('keydown', (e) => {
    console.log("Bosilgan tugma:", e.key);   // "Enter", "ArrowUp", "a"
    console.log("Fizik kod:", e.code);       // "KeyA", "Digit1"
});

Senior Dasturchi Maslahati (Clean Code)

DOM bilan ishlashda har doim Event Delegation (bitta umumiy ota elementga event qo'yish) orqali xotira sarfini tejang.

Xotirada Nima Bo'ladi? (Under The Hood)

DOM elementlari brauzer xotirasida (C++ Render Tree) saqlanadi. Har safar DOM o'zgarganda layout qayta hisoblanishi mumkin.
