04. Advanced JavaScript (10X Versiya)

AJAX va Mijoz-Server (Client-Server) Arxitekturasi

AJAX nima, HTTP protokoli qanday ishlaydi, so'rov va javob (Request-Response) tuzilmasi.

🌐 1. AJAX Nima?

AJAX — Asynchronous JavaScript And XML so'zlarining qisqartmasi. U veb-sahifaga butun sahifani qayta yuklamagan holda fonda serverdan ma'lumot olish yoki jo'natish imkonini beradi.

🔄 2. HTTP So'rov Turlari (Metodlar)

  • GET: Serverdan ma'lumot olish.
  • POST: Serverga yangi ma'lumot jo'natish.
  • PUT / PATCH: Mavjud ma'lumotni yangilash.
  • DELETE: Ma'lumotni o'chirish.

Senior Dasturchi Maslahati (Clean Code)

Xotirada Nima Bo'ladi? (Under The Hood)
