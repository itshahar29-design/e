HTML Formalar Bilan Ishlash: submit Hodisasi va e.preventDefault()

Formalardan ma'lumot olish, e.preventDefault() bilan sahifa yangilanishini to'xtatish va real-time validatsiya.

📝 1. Forma Hodisasi va e.preventDefault()

HTML formalari (<form>) jo'natilganda (submit bo'lganda) brauzer odatda sahifani qayta yuklab yuboradi. JavaScriptda sahifa yangilanmasdan ma'lumotlarni qabul qilish uchun e.preventDefault() ishlatiladi.

form.addEventListener('submit', (e) => {
    e.preventDefault(); // Sahifa qayta yuklanishini to'xtatadi!
    const username = form.username.value;
    console.log("Foydalanuvchi:", username);
});
