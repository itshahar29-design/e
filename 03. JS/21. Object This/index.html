03. JS Darslari (10X Versiya)

Obyektlarda "this" Kalit So'zi: Kontekst va Qopqonlar

Metod ichida this nima, global kontekstda this, arrow funksiyalarda this yo'qligi va uning sabablari.

🧭 1. "this" Nima?

JavaScript da this kalit so'zi joriy funksiya qaysi obyekt tomonidan chaqirilayotganini (ijro kontekstini) ko'rsatadi.

const user = {
    ism: "Zuhra",
    salom: function() {
        console.log("Salom, men " + this.ism); // this -> user obyekti
    }
};
user.salom(); // "Salom, men Zuhra"

⚠️ 2. Arrow Funksiyalardagi Katta Tuzoq

Arrow funksiyalarda o'zining this konteksti bo'lmaydi! Ular this ni o'zining tashqi o'rab turgan sohasidan (lexical scope) oladi. Shuning uchun obyekt metodlari sifatida arrow funksiya yozish TAVSIYA ETILMAYDI:

const car = {
    nom: "BMW",
    korish: () => {
        console.log(this.nom); // undefined! (Chunki bu yerda this -> window)
    }
};
