03. JS Darslari (10X Versiya)

Type Coercion (Turlar Konvertatsiyasi): Aniq va Noaniq O'tish

JavaScriptda ma'lumot turlarining avtomatik o'zgarishi (Type Coercion) va qo'lda o'tkazish (Explicit Conversion).

🔄 1. Noaniq (Implicit / Avtomatik) Konvertatsiya

JavaScript dinamik tiplangan til bo'lgani uchun, turli turlarni amallarda qatnashtirganda ularni avtomatik tarzda o'zgartiradi:

// 1. Matnga aylanish (+ operatori bo'lsa)
"Salom " + 5      // "Salom 5"
"10" + 20         // "1020"

// 2. Songa aylanish (-, *, /, % operatorlarida)
"20" - 5          // 15
"10" * "3"        // 30
+"100"            // 100 (Unar plyus tezkor songa o'tkazadi)

// 3. Boolean ga aylanish
!0                // true
!1                // false

🛠️ 2. Aniq (Explicit / Qo'lda) O'tkazish

Kutilmagan xatolarning oldini olish uchun har doim o'zingiz aniq o'tkazishingiz tavsiya qilinadi:

  • Number("123") — Raqamga o'tkazadi (harflar bo'lsa NaN).
  • parseInt("45px") — Matn boshidagi butun sonni ajratib oladi (45).
  • parseFloat("3.14rem") — Kasr sonni ajratib oladi (3.14).
  • String(123) yoki (123).toString() — Matnga o'tkazadi.
  • Boolean(qiymat) — Mantiqiy qiymatga o'tkazadi.

Senior Dasturchi Maslahati (Clean Code)

Har doim kodingizni toza, tushunarli va modulli qilib yozing. DRY (Don't Repeat Yourself) va KISS (Keep It Simple) tamoyillariga amal qiling.

Xotirada Nima Bo'ladi? (Under The Hood)

JavaScript dvigateli (V8) o'zgaruvchilarni Call Stack (primitivlar uchun) va Memory Heap (obyektlar va funksiyalar uchun) ga ajratadi.
