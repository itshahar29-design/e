03. JS Darslari (10X Versiya)

switch-case Boshqaruv Konstruksiyasi: Qoidalar va break

Bir xil o'zgaruvchini ko'p qiymatlarga tekshirish, break ning roli, guruhlash va default bloki.

🕹️ 1. switch-case Qachon Ishlatiladi?

Bitta o'zgaruvchining qiymatini ko'p sonli variantlar bilan solishtirish kerak bo'lganda if-else if-else zanjiridan ko'ra switch-case ancha toza va o'qishli kod beradi.

let haftaKuni = 3;

switch (haftaKuni) {
    case 1:
        console.log("Dushanba");
        break;
    case 2:
        console.log("Seshanba");
        break;
    case 3:
        console.log("Chorshanba");
        break;
    default:
        console.log("Bunday kun yo'q");
}

⚠️ 2. break Nima Uchun Shart?

Agar case oxiriga break qo'yilmasa, dastur keyingi case lardagi kodlarni ham shartiga qaramay ketma-ket bajarib ketadi (bunga fall-through deyiladi).

Eslatma: switch har doim qat'iy tenglik === orqali solishtiradi!

Senior Dasturchi Maslahati (Clean Code)

Har doim kodingizni toza, tushunarli va modulli qilib yozing. DRY (Don't Repeat Yourself) va KISS (Keep It Simple) tamoyillariga amal qiling.

Xotirada Nima Bo'ladi? (Under The Hood)

JavaScript dvigateli (V8) o'zgaruvchilarni Call Stack (primitivlar uchun) va Memory Heap (obyektlar va funksiyalar uchun) ga ajratadi.
