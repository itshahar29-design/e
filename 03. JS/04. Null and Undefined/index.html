03. JS Darslari (10X Versiya)

Null va Undefined Farqi, Xotira Tuzilmasi va Tuzoqlar

Bo'sh qiymatlar: undefined nima uchun avtomatik, null nima uchun ataylab qo'yiladi, typeof null xatosi va Nullish Coalescing (??).

❓ 1. Undefined Nima?

undefined — o'zgaruvchi e'lon qilingan, lekin unga hali hech qanday qiymat berilmagan holat. JavaScript dvigateli unga avtomatik tarzda undefined qiymatini biriktiradi.

let a;
console.log(a); // undefined
console.log(typeof a); // "undefined"

⛔ 2. Null Nima?

null — bu dasturchi tomonidan ataylab beriladigan "hech narsa yo'q", "bo'sh obyekt" ma'nosini anglatuvchi maxsus qiymat.

let foydalanuvchiManzili = null; // Hozircha manzil kiritilmagan
console.log(foydalanuvchiManzili); // null
console.log(typeof null); // "object" -> Bu JS ning 1995-yildan qolgan mashhur xatosidir!

⚖️ 3. Taqqoslash va Nullish Coalescing (??)

console.log(null == undefined);  // true  (Ikkalasi ham qiymat yo'qligi)
console.log(null === undefined); // false (Turlari har xil: object vs undefined)

// Nullish Coalescing (??) - faqat null yoki undefined bo'lsa default qiymat beradi:
let son = 0;
console.log(son || 10); // 10 (Chunki 0 Falsy!)
console.log(son ?? 10); // 0  (Chunki 0 null yoki undefined emas!)
