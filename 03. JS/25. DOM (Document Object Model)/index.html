03. JS Darslari (10X Versiya)

DOM (Document Object Model) Chuqur Tahlili va Daraxt Arxitekturasi

Brauzer HTML ni qanday o'qiydi, DOM daraxti tuzilmasi, Node turlari va ota-bola (parent-child) munosabatlari.

🌳 1. DOM Nima?

DOM (Document Object Model) — bu HTML hujjatning JavaScript tomonidan o'zgartirilishi mumkin bo'lgan daraxtsimon obyektli modelidir.

Brauzer HTML faylni yuklagan zahoti uni xotirada DOM daraxtiga aylantiradi. Daraxtning ildizi document obyekti hisoblanadi.

🌿 2. DOM Tugunlari (Nodes)

  • Element Node: Barcha HTML teglari (<div>, <p>, <h1>).
  • Text Node: Teglar ichidagi barcha matnlar.
  • Comment Node: HTML izohlari (<!-- ... -->).

Senior Dasturchi Maslahati (Clean Code)

Har doim kodingizni toza, tushunarli va modulli qilib yozing. DRY (Don't Repeat Yourself) va KISS (Keep It Simple) tamoyillariga amal qiling.

Xotirada Nima Bo'ladi? (Under The Hood)

JavaScript dvigateli (V8) o'zgaruvchilarni Call Stack (primitivlar uchun) va Memory Heap (obyektlar va funksiyalar uchun) ga ajratadi.
