03. JS Darslari (10X Versiya)

Template Literals (Shablon Qatorlar) va Backticklar

Eskicha string ulash muammolari, Backtick (``), ${ifoda} interpolatsiyasi va dinamik HTML kartochkalar yaratish.

✨ 1. Nima Uchun Template Literals Kerak?

ES6 gacha stringlarni o'zgaruvchilar bilan birlashtirish uchun + operatori ishlatilar edi. Bu juda noqulay va xatolarga moyil edi:

// Eskicha usul (ES5):
let ism = "Bekzod";
let yosh = 22;
let kasb = "Dasturchi";
let xabar = "Salom, mening ismim " + ism + ", yoshim " + yosh + " da va men " + kasb + "man.";

// Zamonaviy usul (ES6 Template String):
let zamonaviy = `Salom, mening ismim ${ism}, yoshim ${yosh} da va men ${kasb}man.`;

📄 2. Ko'p Qatorli Matnlar va HTML Yaratish

Backticklar yordamida matnni hech qanday \n yoki + belgilarisiz istalgancha yangi qatorga tushirishingiz va bevosita HTML yozishingiz mumkin:

const userCardHtml = `
    <div class="card">
        <h3>${ism}</h3>
        <p>Status: ${yosh >= 18 ? "Katta yoshli" : "Voyaga yetmagan"}</p>
    </div>
`;

Senior Dasturchi Maslahati (Clean Code)

Har doim kodingizni toza, tushunarli va modulli qilib yozing. DRY (Don't Repeat Yourself) va KISS (Keep It Simple) tamoyillariga amal qiling.

Xotirada Nima Bo'ladi? (Under The Hood)

JavaScript dvigateli (V8) o'zgaruvchilarni Call Stack (primitivlar uchun) va Memory Heap (obyektlar va funksiyalar uchun) ga ajratadi.
