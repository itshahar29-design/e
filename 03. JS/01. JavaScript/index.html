03. JS Darslari (10X Versiya)

JavaScript Asoslari, V8 Dvigateli va O'zgaruvchilar

JavaScript tarixi, V8 dvigateli, HTML bilan bog'lanish, brauzer bilan muloqot va var, let, const ning tub farqlari.

🌐 1. JavaScript Tarixi va ECMAScript

JavaScript 1995-yilda Brendan Eich tomonidan atigi 10 kun ichida Netscape brauzeri uchun yaratilgan. Bugungi kunda JS veb-sahifalarga "jon" beruvchi (dinamiklik, animatsiya, foydalanuvchi harakatlariga javob) yagona standart dasturlash tilidir.

💡 Hayotiy O'xshatish: Agar HTML binoning g'ishtlari va devorlari (skeleti), CSS uning bo'yog'i va dizayni (tashqi ko'rinishi) bo'lsa, JavaScript binoning elektr tarmog'i, lifti va aqlli boshqaruv tizimidir!

⚡ 2. Brauzer Dvigateli (V8) Qanday Ishlaydi?

Google Chrome va Node.js o'zida V8 dvigatelini ishlatadi. U JavaScript kodini mashina kodiga (0 va 1 ga) JIT (Just-In-Time) Compilation orqali bir zumda aylantiradi. Asosiy ikki qismdan iborat:

  • Memory Heap: O'zgaruvchilar va obyektlar uchun xotira ajratiladigan joy.
  • Call Stack: Qaysi funksiyalar bajarilayotganini tartib bilan ushlab turuvchi stek.

📦 3. O'zgaruvchilar: var vs let vs const

Ma'lumotlarni kompyuter xotirasida saqlash uchun o'zgaruvchilardan foydalanamiz:

// 1. var (ES5 - eskirgan, tavsiya etilmaydi!)
var yosh = 20;
var yosh = 25; // Xatosiz qayta e'lon qilish mumkin (juda xavfli!)

// 2. let (ES6 - qiymati o'zgarishi mumkin)
let ball = 85;
ball = 90; // Qiymatini yangilash mumkin, lekin qayta 'let ball' qilib bo'lmaydi

// 3. const (ES6 - o'zgarmas doimiy qiymat)
const PI = 3.14159;
// PI = 3.15; // XATO! Assignment to constant variable.
⚠️ Oltin Qoida: Har doim const dan foydalaning. Faqat qiymati keyinroq o'zgarishi aniq bo'lgandagina let ishlating. Hech qachon var ishlatmang!
