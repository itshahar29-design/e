03. JS Darslari (10X Versiya)

Ko'rinish Sohasi (Scope): Global, Funksiya va Blok Sohalari

O'zgaruvchilarning ko'rinish doirasi, var ning block scope ga bo'ysunmasligi va Scope Chain (ko'rinish zanjiri).

🗺️ 1. Scope (Ko'rinish Sohasi) Nima?

Scope — o'zgaruvchilarga kodning qaysi qismlaridan kirish (murojaat qilish) mumkinligini belgilovchi chegara hududidir.

  • Global Scope: Har qanday blok va funksiyalardan tashqarida joylashgan soha. U yerdagi o'zgaruvchiga hamma joydan murojaat qilish mumkin.
  • Function Scope: Funksiya ichida e'lon qilingan o'zgaruvchilar faqat o'sha funksiya ichidagina yashaydi.
  • Block Scope: { ... } jingalak qavslar ichi. let va const faqat o'sha blok ichida mavjud bo'ladi.

⚠️ 2. Nega 'var' Xavfli?

if (true) {
    var eskirgan = "Men varman";
    let zamonaviy = "Men letman";
}

console.log(eskirgan);  // "Men varman" (Blokdan tashqariga sizib chiqdi!)
console.log(zamonaviy); // ReferenceError: zamonaviy is not defined

Har doim kodingizni toza, tushunarli va modulli qilib yozing. DRY (Don't Repeat Yourself) va KISS (Keep It Simple) tamoyillariga amal qiling.
