03. JS Darslari (10X Versiya)

Boolean Qiymatlar, Taqqoslash Operatorlari va Truthy / Falsy

Mantiqiy haqiqat (true/false), taqqoslash turlari (== vs ===), va JavaScriptdagi 8 ta Falsy qiymatlar ro'yxati.

⚖️ 1. Taqqoslash Operatorlari

JavaScript da qiymatlarni solishtirish uchun quyidagi operatorlar mavjud:

  • === (Qat'iy tenglik) — Qiymatni ham, ma'lumot turini ham tekshiradi. 5 === '5' // false
  • == (Kuchsiz tenglik) — Turni avtomatik o'zgartirib taqqoslaydi (Tavsiya etilmaydi!). 5 == '5' // true
  • !== (Qat'iy teng emas)
  • >, <, >=, <= (Katta, kichik, katta-teng, kichik-teng)

🔥 2. JS Dagi 8 ta Falsy Qiymatlar

Quyidagi 8 ta qiymat Boolean ga aylantirilganda har doim false bo'ladi:

  1. false
  2. 0 (va -0)
  3. 0n (BigInt noli)
  4. "" (bo'sh qator)
  5. null
  6. undefined
  7. NaN
🌟 Eslab Qoling: Yuqoridagi 8 tasidan boshqa HAR QANDAY qiymat (masalan "0", [], {}, "false") — TRUTHY hisoblanadi!
