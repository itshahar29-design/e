03. JS Darslari (10X Versiya)

Massivlar (Arrays): Indekslash, Metodlar va Manipulyatsiya

Massivlar tuzilmasi, push, pop, shift, unshift, slice, splice, indexOf va includes metodlarining jonli tahlili.

📚 1. Massiv (Array) Nima?

Massiv — bir nechta qiymatlarni bitta o'zgaruvchida tartiblangan ro'yxat ko'rinishida saqlash vositasidir. Elementlar 0-indeksdan boshlab raqamlanadi.

let mevalar = ["Olma", "Banan", "Shaftoli", "Gilos"];
console.log(mevalar[0]); // "Olma"
console.log(mevalar.length); // 4

⚙️ 2. Eng Muhim Massiv Metodlari

  • push(el) — Massiv oxiriga element qo'shadi.
  • pop() — Massiv oxiridagi elementni sug'urib oladi.
  • unshift(el) — Massiv boshiga yangi element qo'shadi.
  • shift() — Massiv boshidagi birinchi elementni olib tashlaydi.
  • slice(bosh, tugash) — Nusxa ko'chirib qirqib oladi (asl massiv o'zgarmaydi).
  • splice(indeks, soni, qo'shimcha) — Elementlarni o'chiradi yoki o'rniga qo'shadi (asl massivni o'zgartiradi!).
