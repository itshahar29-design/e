Virtual DOM va Real DOM Chuqur Tahlili, Reconciliation Mexanizmi

Real DOM nima uchun sekin, Virtual DOM ning xotirada ishlash prinsipi va Diffing algoritmi siri.

🌳 1. Real DOM Nega Sekin?

Brauzerning Real DOM daraxtida bitta kichik element o'zgarsa ham, brauzer butun sahifaning geometriyasini qayta hisoblashi (Reflow / Layout) va piksellarni qaytadan chizishi (Repaint) kerak bo'ladi. Bu minglab elementlari bor murakkab saytlarda juda katta sekinlashuvga olib keladi.

⚡ 2. Virtual DOM (VDOM) Qanday Qutqaradi?

Virtual DOM — Real DOM ning kompyuter xotirasidagi yengil JavaScript obyekt nusxasidir. React quyidagi 3 qadamda ishlaydi:

  1. Yangi VDOM: Har safar state o'zgarganda xotirada yangi Virtual DOM daraxti hosil bo'ladi.
  2. Diffing Algoritmi: Yangi VDOM eski VDOM bilan taqqoslanadi va aynan qaysi element o'zgargani bir zumda topiladi.
  3. Reconciliation: Faqat o'sha o'zgargan bitta tugun Real DOM ga yuboriladi. Qolgan 99% sahifa umuman qayta chizilmaydi!

Senior Dasturchi Maslahati (Clean React Code)

Reactda komponentlarni har doim kichik, bitta vazifani bajaruvchi (Single Responsibility) qismlarga ajrating.

React Dvigateli Xotirada Nima Qiladi?

React komponentlari Virtual DOM da xotirada saqlanadi. Faqat state o'zgarganda Diffing algoritmi ishlab DOM ga yangi tugun boradi.
