JSX Formati Qoidalari, Komponentlar, State va Props Asoslari

JSX ning 5 ta qat'iy qoidasi, Props orqali ma'lumot uzatish va useState hooki orqali reaktiv holat yaratish.

📜 1. JSX Nima va Uning 5 Ta Qat'iy Qoidasi

JSX — JavaScript XML so'zlarining qisqartmasi bo'lib, JavaScript kodi ichida HTML ga o'xshash belgilarni yozish imkonini beradi. Brauzerlar JSX ni to'g'ridan-to'g'ri tushunmaydi, Babel uni React.createElement() ga aylantirib beradi.

  1. Yagona Ota Element: Komponent har doim bitta ota element yoki Fragment <>...</> qaytarishi shart.
  2. Barcha Teglar Yopilishi Shart: <img src="..." />, <br />, <input />.
  3. camelCase Atributlar: class o'rniga className, for o'rniga htmlFor, onclick o'rniga onClick.
  4. Jingalak Qavslar {}: JSX ichida JavaScript o'zgaruvchilari yoki ifodalarini ishlatish uchun {ism} jingalak qavs ishlatiladi.
  5. Komponent Nomlari Katta Harf Bilan: function UserCard() (kichik harf bilan boshlansa HTML tegi deb o'ylab xato beradi).

🎁 2. Props vs State Farqi

  • Props (Properties): Ota komponentdan bola komponentga parametr sifatida uzatiladigan tashqi ma'lumot (o'zgartirib bo'lmaydi - Read Only).
  • State: Komponentning ichki shaxsiy xotirasi bo'lib, u o'zgarganda komponent avtomatik ravishda qayta chiziladi (Reaktivlik).

Senior Dasturchi Maslahati (Clean React Code)

Reactda komponentlarni har doim kichik, bitta vazifani bajaruvchi (Single Responsibility) qismlarga ajrating.

React Dvigateli Xotirada Nima Qiladi?

React komponentlari Virtual DOM da xotirada saqlanadi. Faqat state o'zgarganda Diffing algoritmi ishlab DOM ga yangi tugun boradi.
