05. React.js (10X Versiya)

React Muhitini O'rnatish: Node.js, NPM, Vite va Loyiha Arxitekturasi

NodeJS o'rnatish, NPM paketlari, zamonaviy Vite orqali loyiha yaratish va papkalar tuzilmasi.

🛠️ 1. Node.js va NPM Nima?

Node.js — JavaScript kodini brauzerdan tashqarida, kompyuterning o'zida ishga tushiruvchi V8 muhitidir. Frontend dasturchiga Node.js paketlarni o'rnatish, kodni minifikatsiya qilish va serverni yurgizish uchun kerak bo'ladi.

NPM (Node Package Manager) — dunyodagi eng katta ochiq kodli dasturiy paketlar va kutubxonalar omboridir.

⚡ 2. Vite Nima va Nega CRA (Create-React-App) Eskirdi?

Eski create-react-app juda sekin ishlar edi (Webpack sababli). Zamonaviy Vite esa brauzerning mahalliy ES Modullari ustiga qurilgan bo'lib, loyihani bir zumda (10-20 millisekundda) ishga tushiradi!

# 1. Yangi Vite React loyihasini ochish:
npm create vite@latest mening-loyiham -- --template react

# 2. Papkaga kirish va kerakli paketlarni o'rnatish:
cd mening-loyiham
npm install

# 3. Dasturchi serverini yoqish:
npm run dev

📁 3. React Loyihasi Papkalar Tuzilmasi

  • node_modules/ — Loyihaga yuklab olingan barcha tashqi kutubxonalar.
  • public/ — O'zgarmas statik fayllar (favicon, rasmlar).
  • src/ — Dasturchi kod yozadigan asosiy papka.
    • main.jsx — Ilovaning kirish nuqtasi (React ni DOM ga ulaydi).
    • App.jsx — Asosiy bosh komponent.
    • App.css / index.css — Stillar.
  • package.json — Loyiha pasporti (nomi, versiyasi, buyruqlari va paketlar ro'yxati).
  • vite.config.js — Vite konfiguratsiya fayli.

Senior Dasturchi Maslahati (Clean React Code)

Reactda komponentlarni har doim kichik, bitta vazifani bajaruvchi (Single Responsibility) qismlarga ajrating.

React Dvigateli Xotirada Nima Qiladi?

React komponentlari Virtual DOM da xotirada saqlanadi. Faqat state o'zgarganda Diffing algoritmi ishlab DOM ga yangi tugun boradi.
