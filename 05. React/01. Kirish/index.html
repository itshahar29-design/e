05. React.js (10X Versiya)

React.js ga Kirish: Nima Uchun React? SPA vs MPA va Deklarativ UI

React nima, Jordan Walke va Meta tarixi, imperativ vs deklarativ dasturlash va komponentli arxitektura.

⚛️ 1. React Nima va U Nima Uchun Yaratildi?

React — 2013-yilda Meta (Facebook) muhandisi Jordan Walke tomonidan yaratilgan, foydalanuvchi interfeyslarini (UI) qurish uchun mo'ljallangan dunyodagi eng mashhur JavaScript kutubxonasidir.

💡 Oddiy JS vs React Farqi: Oddiy JavaScriptda siz har bir elementni qo'lda topib (document.getElementById), matnini o'zgartirishingiz kerak (Imperativ — "qanday qilishni" ko'rsatish). Reactda esa siz shunchaki "Ekranda mana bu ma'lumot ko'rinsin" deysiz (Deklarativ), qanday qilib DOM ni eng tez yangilashni React o'zi hal qiladi!

🚀 2. SPA (Single Page Application) Nima?

An'anaviy saytlarda (MPA) har bir havolaga bosganda butun sahifa oq rang bo'lib serverdan qayta yuklanadi. React esa bitta yagona index.html sahifada ishlaydi. Sahifa qayta yuklanmaydi, faqat kerakli komponentlar bir zumda o'zgaradi (mobil ilova kabi tez ishlaydi)!

🧩 3. Komponentli Arxitektura

React ilovasi xuddi Lego o'yinchog'i kabi mustaqil, qayta ishlatiluvchi bo'laklardan (komponentlardan) tashkil topadi:

  • Header.jsx — Sayt sarlavhasi
  • Sidebar.jsx — Yon panel
  • ProductCard.jsx — Tovar kartochkasi
  • Footer.jsx — Sayt pastki qismi

Senior Dasturchi Maslahati (Clean React Code)

Reactda komponentlarni har doim kichik, bitta vazifani bajaruvchi (Single Responsibility) qismlarga ajrating.

React Dvigateli Xotirada Nima Qiladi?

React komponentlari Virtual DOM da xotirada saqlanadi. Faqat state o'zgarganda Diffing algoritmi ishlab DOM ga yangi tugun boradi.
