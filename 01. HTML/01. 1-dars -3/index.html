1-dars: HTML Asoslari, Internet Qanday Ishlaydi va Barcha Boshlang'ich Teglar

Internet arxitekturasi, HTML5 sintaksisi, barcha matn va ro'yxat teglari, havolalar, rasmlar va semantik tuzilma chuqur tahlili.

🌐 1. Internet Qanday Ishlaydi? (Client-Server Arxitekturasi)

Har safar brauzeringizga google.com yoki boshqa manzilni kiritganingizda, orqa fonda quyidagi jarayonlar yuz beradi:

  1. Mijoz (Client): Sizning brauzeringiz (Chrome, Edge, Safari) so'rov (Request) yuboradi.
  2. DNS (Domain Name System): google.com kabi inson tushunadigan nomni serverning haqiqiy IP manziliga (masalan: 142.250.185.206) aylantirib beradi.
  3. Server: Dunyoning boshqa nuqtasida kechayu-kunduz ishlab turgan kuchli kompyuter so'rovni qabul qilib, javob (Response) sifatida HTML, CSS va JavaScript fayllarini yuboradi.
  4. Brauzer Renderingi: Brauzer ushbu kodlarni o'qib, ularni siz ko'rib turgan chiroyli vizual sahifaga aylantiradi.

🏗️ 2. HTML Nima?

HTML (HyperText Markup Language) — bu dasturlash tili emas, balki Gipermatnli Belgilash Tilidir. U veb-sahifaning skeleti va poydevorini quradi.

HTML teglari (tags) orqali brauzerga qaysi qism sarlavha, qaysi biri matn, rasm yoki tugma ekanligini bildiramiz.

📋 4. Ro'yxatlar: Tartibsiz (<ul>) va Tartibli (<ol>)

Tartibsiz ro'yxat (Unordered List):

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
</ul>
  • HTML5
  • CSS3
  • JavaScript

Tartibli ro'yxat (Ordered List):

<ol type="1">
  <li>Nazariyani o'rganish</li>
  <li>Amaliy kod yozish</li>
  <li>Loyiha qilish</li>
</ol>
  1. Nazariyani o'rganish
  2. Amaliy kod yozish
  3. Loyiha qilish

🎯 Mustaqil Amaliy Vazifa (Homework)

  1. O'zingiz haqingizda kichik tarjimai hol (CV) sahifasini tuzing.
  2. Sahifada <h1> da to'liq ismingiz, <p> da o'zingiz haqingizda ma'lumot bo'lsin.
  3. Yoqtirgan 5 ta kitobingizni <ol> tartibli ro'yxatida yozing.
  4. Boshlang'ich ko'nikmalaringizni <ul> ro'yxatida keltiring.
  5. Kamida 3 ta jumlada <b>, <mark>, va <del> teglarini ishlating.

Senior Dasturchi Maslahati (Clean Semantic HTML)

HTML yozishda div va span lardan haddan tashqari ko'p foydalanmang (Div soup). Har doim semantik teglardan (header, main, section, article, nav, footer) foydalaning. Bu saytingizni qidiruv tizimlari (Google SEO) va imkoniyati cheklanganlar (Accessibility) uchun 10 barobar qulay qiladi.

Brauzer Qanday O'qiydi? (DOM Parsing)

Brauzer HTML ni olgandan so'ng dastlab Tokenization (belgilarga ajratish), so'ngra DOM daraxti (Node Tree) quradi. Har bir ochilgan teg xotirada alohida Element Node obyektiga aylanadi.
